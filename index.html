04Brand · UI/UX · Motion

Personal concept

Uštedi

FigmaClaude Code

A grocery price-comparison app: brand identity, UX and UI, on a Figma system of 146 variables.

Personal concept, never shipped. Prices are sample data, and store names and logos belong to their owners.

Role
Brand identity, UX flows, UI, design system, launch ad
System
146 variables: Brand 50 · Alias 35 · Mapped 25 (light and dark) · Responsive 36 · 22 text styles in National Park

Build a shopping list and it finds the nearest store where most of it is cheapest. Uštedi means “save” in Croatian, so the € in the wordmark says what the product does.

Wireframes came first, then the logo. The palette and type grew alongside the UI, and every value is a variable: 146 in four collections, with light and dark modes from one file. Every screen carries annotations for its font sizes and colour roles, so it can be built without guessing.

The launch ad animates my own Figma screens on Figma’s timeline (taps, typing, screen transitions), then puts them on a 3D phone in Ultramock. The captions and end card are rendered from code on top.

05AI imagery · Motion

Unofficial concept

AI production & motion

FLORAAffinityClaude Code

AI speeds it up. I decide. The production system behind two unofficial Favbet pieces: the Derby Weekend campaign, and the Autumn Jackpot casino key visual with its six-second loop.

Unofficial concept in Favbet’s visual language. Not affiliated with Favbet.

Role
Art direction, production pipeline and QA rules, motion
AI cost
About $11 of generation for all the Favbet work, Derby Weekend included

Instead of resizing every format by hand, I built a small production system:

  1. Art direction. Generations in FLORA (Nano Banana, FLUX, Ideogram, Topaz). I choose, or regenerate.
  2. One source. A tokens file: RGB and CMYK colour, four type sizes, safe zones and the legal line.
  3. Layout. Scripts drive Affinity and lay out every format from one key visual.
  4. QA gate. Every export is checked for pixel size, type contrast, resolution and file weight.
  5. Finish. I hand-finish every artboard in Affinity, then export.

Claude Code wrote the code under my direction. The concept, the choice between generations, the layouts and the hand-finishing stay mine. When an image is wrong, I regenerate it rather than patch it.

The loop renders its type, coins and light from code (HTML, headless Chrome, ffmpeg), frame by frame, over a forest background I animated with AI (Luma) and cut to loop without a seam.
